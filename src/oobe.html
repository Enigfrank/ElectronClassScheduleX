配置您的课表

首先,您需要配置课程表信息,这是应用正常运行的基础

📚

为什么需要配置课表？

配置决定了应用显示的课程内容,时间安排和倒计时功能.正确配置后,应用将自动显示当前课程和倒计时.

配置步骤

  1. 点击下方的"打开配置文件夹"按钮
  2. 编辑 scheduleConfig.js 文件
  3. 可选: 将文件上传到config.cavendi.top进行可视化编辑
  4. 按照文件中的注释修改课程信息
  5. 保存文件后请点击下一步

配置文件示例

// 科目名称映射
subject_name: {
    "YW": "语文",
    "SX": "数学",
    "YY": "英语",
    // ... 更多科目
}

// 每日课程安排
daily_class: {
    1: {  // 星期一
        classList: ["YW", "SX", "YY", ...],
        timetable: "default"
    }
}
