Schedule Config

配置您的课表

请先准备课程表信息，这是应用显示课程、时间安排和倒计时的基础

配置步骤

  1. 请直接点击下一步,将会生成默认课表
  2. 请前往仪表盘配置

配置文件示例

// 科目名称映射
subject_name: {
    "YW": "语文",
    "SX": "数学",
    "YY": "英语"
}

// 每日课程安排
daily_class: {
    1: {
        classList: ["YW", "SX", "YY"],
        timetable: "default"
    }
}
