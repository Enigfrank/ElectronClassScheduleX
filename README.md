

> 此项目对原版 `ECS V1` 进行更改 [原仓库](https://github.com/EnderWolf006/ElectronClassSchedule)

## 📋 功能说明
- 显示每日/每周课程安排
- 支持多周课表轮换
- 窗口置顶、点击穿透
- 本地存储，无需联网

## 构建方法
 - 1. 下载本仓库
 - 2. 执行 npm install ; npm rebuild
 - 3. 调试使用 npm start 构建使用npm run build


## 🔐 隐私政策
本程序为纯本地应用，**不会收集、存储或传输任何用户数据**到网络系统。所有课表数据仅保存在用户本地设备。
