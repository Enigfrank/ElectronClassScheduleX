

> 此项目对原版 `ECS V1` 进行了大量更改 [原仓库](https://github.com/EnderWolf006/ElectronClassSchedule)

## 构建方法
 - 1. 下载本仓库
 - 2. 执行 npm install ; npm rebuild
 - 3. 调试使用 npm start 构建使用npm run build
